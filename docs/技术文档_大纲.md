## 零、核心亮点预览 (Executive Summary)

*本节置于正式技术文档卷首（第 1 页），紧扣赛题“含核心亮点预览”要求，以 8 条“核心结论 + 权威实测数字”直观呈现作品核心竞争力：*

1. **工业级高可靠 PCIe 异构高速互联通道**：打通盘古 100Pro+ 插接 OK3568 P29 槽位的 PCIe Gen2 x2 链路，实测板卡到主机长传输吞吐达 **896 MB/s**（主机到板卡实测峰值 **861 MB/s**），在 5 分钟 485 轮双向交替压力测试中取得 **0 失败、PCIe AER 与 RAS DES 硬件错误严格为 0** 的优异表现（出处：`PCIe_DMA提速_20261018.md:200-201`）。
2. **端到端纯硬件零拷贝多路视频中枢**：独创“MPP 硬件解码 $\rightarrow$ RGA 2D 派生 $\rightarrow$ 门铃 DMA 触发 $\rightarrow$ FPGA DDR3 帧存 $\rightarrow$ 四宫格硬件排版”全链路，四路 960×540@30fps 并发推流在 RGB565 格式下仅占用 **124.4 MB/s** 总线带宽，**对 861 MB/s 实测峰值负载仅为 14.5%**（原始 RGB888 占 **21.7%**），CPU 内存搬移与画面撕裂开销彻底归零（出处：草稿 §4.2，`PCIe_DMA提速_20261018.md:204`）。
3. **纳秒级时序收敛与高紧凑片上资源平衡**：最新 cam11 固件在包含车道线、斑马线及四路视频 Hub 满载工况下，全局建立时间最差余量 **Setup WNS = +0.340 ns (340 ps)**（`pix_clk` 148.5 MHz 域），总负余量 TNS 严格为 **0.000 ns**；以精简资源（**LUT 40.0%、FF 19.3%、DRM 63.8%、APM 25.4%**）实现单片高密度集成（出处：`build_cam11_s1.log:20529, 20551-20577`）。
4. **NPU 深度量化与频点极限能效调优**：部署定制 $960 \times 320$ 车载带状视野 YOLOv6n INT8 模型（`b5_v6n_band.rknn`），超频运行于 900 MHz 最大频点，**单帧推理耗时中位数降至 17.55 ms**（较 600 MHz 降低 **12.9%**）；5 分钟浸泡压测板温稳定在 **46.7–48.3 °C** 且硬件 `0x82C` 欠载计数恒为 **0**（出处：`log/npu_freq_20261029.md:21, 27-29`）。
5. **零依赖极低开销纯 C 交通信号灯引擎**：完全脱离 OpenCV 等重型视觉库，纯 C99 实现 `tl_det` 单帧运算 0 动态内存分配（**0 malloc/free**）；在 7 段官方评测视频共 2678 帧全量数据集上实现 **检测级 RAW 100.00% (2678/2678) 逐帧对齐**，官方 SIG 用例通过数达 **63 / 69 (91.3%)**（出处：`tools/adas/host_test/report.md:33, 67`）。
6. **单遍光栅流式车道线硬件加速核**：提出无整帧缓存的在线定点最小二乘与 EMA 平滑流水线 `rt_lane_det`，在 5 组基准向量集仿真中**逐行比对全部通过 (row_mismatch = 0) 并核验 12 个关键字段**，门级网表后仿真成功跑通真实路面采样的 **42 帧**时序反标核验（出处：`log/lane_fpga/vectors/README.md:13`）。
7. **嵌入式人机交互与全功能 U 盘启动系统**：自主开发轻量级中文 GUI 与 26×26 GBK 点阵字库引擎（`ui_cjk.bin`），构建开机二选一界面（`mode_select`）、实况监控参数浮窗（`menu_daemon`）与现场 U 盘多格式视频浏览器（`usb_menu`），全系统脱离键盘鼠标、纯靠板载 5 物理按键与 MMIO 闭环控制（出处：`tools/menu/mode_select.c:388`，`tools/menu/usb_menu.c:1461`）。
8. **亚毫秒级声光安全预警闭环响应**：通过单个 32 位 MMIO 寄存器（`0x850`）单周期控制字映射（实测 **`0x0C` 红停、`0x10C` 闯红灯爆闪、`0x08` 绿行**），当视觉检出近距危险障碍物时即刻置位自车道红箭头与 bit8 报警标志，实现 **<1.2 ms** 的硬件级告警直推与全屏鲜红边框闪烁（出处：`tools/usb_feed/adas.c:250-253`，`PCIe_DMA提速_20261018.md:204`）。

### 核对项 c：物理按键命名与 FPGA 内部实际映射行为
- **初稿现状表述**：

- **仓库实际代码事实**：
  - 盘古 100Pro+ 开发板物理上为 5 个独立的微动轻触按键，板载丝印标识为 **KEY0、KEY1、KEY2、KEY3、KEY4**（无摇杆或十字 D-Pad 机械结构）；
  - `fpga/src/disp/rt_osd_ctl.v:318-339` 中真实 RTL 状态机按键映射严格定义如下：
    - **KEY0 (ek=0)**：短按（T_SHORT）$\rightarrow$ 循环切换自车道（`lane <= (lane==2) ? 0 : lane + 1`，0 左 $\rightarrow$ 1 直 $\rightarrow$ 2 右）；
    - **KEY1 (ek=1)**：短按（T_SHORT）$\rightarrow$ 切换车辆启停状态（`moving <= ~moving`）；
    - **KEY2 (ek=2)**：短按（T_SHORT）$\rightarrow$ 左转向请求（`left_req<=1, left_force<=0`）；长按（T_LONG）$\rightarrow$ 强制左转变道（`left_req<=1, left_force<=1`）；
    - **KEY3 (ek=3)**：短按（T_SHORT）$\rightarrow$ 右转向请求（`right_req<=1, right_force<=0`）；长按（T_LONG）$\rightarrow$ 强制右转变道（`right_req<=1, right_force<=1`）；
    - **KEY4 (ek=4)**：短按（T_SHORT）$\rightarrow$ 切换显示模式（`disp_mode <= ~disp_mode`）；长按（T_LONG）$\rightarrow$ 切换输入信号源（`src_sel <= ~src_sel`）；持续按住 3 秒（T_HOLD3）$\rightarrow$ 切入透视标定模式（`cal_mode <= 1`）。
- **核查结论与整改方案**：
  - 草稿混淆了按键硬件形态与动作逻辑（将单键循环误记为上下键，将长按机制误记为组合键）；
  - 必须全文统一采用 KEY0–KEY4 的标准板载名称，准确说明短按、长按、3 秒长按的分级映射行为。

## 六、写作规范与提交建议

*为确保最终提交的技术文档在技术深度、学术规范与视觉排版上达到国家级一等奖水准，制定以下写作规范：*

### 6.1 篇幅与结构规模目标
- **全文目标字数**：正文总字数控制在 **16,000 ～ 20,000 字**（不含附录代码与长日志），预计排版为 28–35 页标准 A4 报告；
- **各章篇幅预算建议**：
  - 核心亮点预览与赛题对照表：2 页（约 1,200 字）；
  - 系统概述与硬件平台架构：4 页（约 2,500 字）；
  - FPGA 片上加速系统设计：6 页（约 3,500 字，重点章节）；
  - 软硬协同数据流与人机交互系统：6 页（约 3,500 字，特色章节）；
  - RK3568 边缘计算与 ADAS 决策软件栈：5 页（约 3,000 字）；
  - 性能数据全景表与验证体系：5 页（约 3,000 字，证据硬核章节）；
  - 赛题测试方式演示、局限性与总结：4 页（约 2,500 字）。

### 6.2 图表与交叉引用编号规范
- **图编号规则**：按章节二级编号，统一采用“**图 章号-序号**”格式（如 图 1-1、图 2-1、图 3-1 ... 图 6-3）；图题置于图正下方，居中，附简要注释；
- **表编号规则**：按章节二级编号，统一采用“**表 章号-序号**”格式（如 表 2-1、表 3-1、表 7-1）；表题置于表正上方，居中，三线表样式排版；
- **正文引用强制要求**：正文中必须出现明确的图表引导句（如“如图 4-1 所示”、“见表 7-1 中序号 3 指标”），严禁出现无正文引用的悬空图表。

### 6.3 数值、单位与专业符号书写规范
- **速率与吞吐量**：统一使用 `MB/s`（兆字节每秒，如 896 MB/s）、`Gbps`（吉比特每秒，如 25.6 Gbps）；严禁混淆 `MB/s` 与 `Mbps`；
- **时延与时间**：秒采用 `s`（如 30 s、5 min），毫秒采用 `ms`（如 17.55 ms），微秒统一采用 `$\mu$s` 或 `us`（如 1.8 $\mu$s），纳秒采用 `ns`（如 +0.340 ns），皮秒采用 `ps`（如 340 ps）；
- **时钟与传输频率**：采用 `MHz`（如 148.5 MHz、900 MHz）及 `GT/s`（吉次传输每秒，如 5.0 GT/s）；
- **图像分辨率与尺寸**：宽度与高度之间一律采用乘号 $\times$（如 $1920 \times 1080$、$960 \times 540$、$960 \times 320$），不用小写字母 x；
- **十六进制数**：寄存器地址与控制字统一采用前缀 `0x` 及大写十六进制字符（如 `0x850`、`0x1A0`、`0x80C`、`0x810`、`0x10C`）。
