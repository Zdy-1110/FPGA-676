# 第三方开源组件与许可证说明 (THIRD_PARTY)

本竞赛工程使用并依赖以下第三方开源组件、库及工具。各组件版权归原作者所有。

## 一、第三方组件列表

### 1. librga
- **版本**：1.9.1 (API 1.9.3)
- **开源许可证**：Apache License 2.0
- **用途**：Rockchip 平台 2D 图形硬件加速库，负责视频画面的格式转换 (NV12/RGB565)、缩放与高效裁剪。
- **分发说明**：本源码包仅包含头文件，动态链接库直接由板端 Linux 系统环境提供。

### 2. MPP (Media Process Platform)
- **版本**：1.0.1
- **开源许可证**：Apache License 2.0
- **用途**：Rockchip 平台高性能硬件视频编解码处理库，用于 USB 摄像头 H.264/H.265/MJPEG 零拷贝硬解码。
- **分发说明**：本源码包仅包含编译适配所需头文件，动态链接库由板端 Linux 系统环境提供。

### 3. rknpu2
- **版本**：1.5.0
- **开源许可证**：Rockchip 开源许可证 (Apache 2.0 兼容)
- **用途**：Rockchip NPU 运行时推理引擎 (librknnrt)，负责执行量化后的神经网络模型。
- **分发说明**：本源码包仅包含调用头文件，运行时库由板端系统环境提供。

### 4. YOLOv6
- **开源许可证**：GNU General Public License v3.0 (GPLv3)
- **用途**：目标检测深度学习网络结构参考及离线训练。
- **分发说明**：仅用于上位机离线模型训练期，源码不随本参赛工程源码包直接分发。

### 5. 离线字体 (msyh / consola)
- **用途**：用于在上位机离线渲染生成 CJK 点阵字库文件 `ui_cjk.bin` 及图标。
- **分发说明**：字体源文件不随源码包分发，仅分发由工具生成的点阵字库数据。
