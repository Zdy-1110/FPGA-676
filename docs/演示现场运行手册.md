# 演示现场运行手册

> 适用：紫光同创 PG2L100H（盘古 100Pro+）+ 飞凌 OK3568-C，HDMI 1920×1080 四宫格。
> 原则：**先体检、再演示；不热插拔、不碰 P29、不按住 KEY4 超过 3 秒。**

## 一、物资清单

- 两块板卡（已用铜柱固定）、12 V 电源、HDMI 线、显示器
- 键盘（板端串口/SSH 备用）、U 盘（英文目录 + 4 个 mp4 + 1 个 jpg/png）
- 手机/采集卡（录制备份）、秒表（可选，用于说明延迟口径）
- 一台笔记本（SSH 到 `192.168.3.51`，跑 `tools/rk_diag.py`）

## 二、上电前 60 秒检查

1. P29 金手指完全插入、两侧铜柱受力均匀；**不做任何热插拔**。
2. 先给 FPGA 板上电，再给 RK3568 上电（共地、防反灌）。
3. HDMI 接显示器，确认显示器输入源正确。
4. U 盘插好；目录里放：`demo/`（英文名）+ 3–4 个 mp4 + 1 张 jpg。可先用脚本生成素材：
   `python tools/make_demo_udisk.py` → `dist/demo_udisk/`（3 段 30 s + 1 张图 + 中文文件名），整目录拷入 U 盘即可。
5. 确认 flash 内为 cam11：上电后 `0x838` 应为 `0x20261029`。

## 三、上电与自检

1. 上电后等待 8–12 s，屏幕应进入**二选一界面**（左：四路摄像头 / 右：U 盘视频流）。
2. 在笔记本执行：

   ```bash
   python tools/rk_diag.py 192.168.3.51
   ```

   期望：`PCIe 端点存在`、`enable=1`、`5.0 GT/s`、`x2`、`固件版本 0x20261029`、`欠载 0` 全部 PASS。
3. 若有 FAIL：先看第四节处置表；不要连续重启超过 2 次。

## 四、演示按键序列

### A. 四路实时（约 40 s）

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 选择界面按 KEY1（左） | 四路实时画面 |
| 2 | 短按 KEY4 | 弹窗出现，`1 LIVE 4CAM` 高亮 |
| 3 | KEY0 移到 `4 LANE:OFF`，KEY1 | 画面出现车道线，状态变 `LANE:ON` |
| 4 | KEY0 移到 `5 VIEW:COLOR`，KEY1 两次 | 灰度 → 二值 |
| 5 | 再按 KEY1 | 回到彩色 |
| 6 | 长按 KEY4 约 3 s 松开 | 回选择界面 |

> 注意：KEY4 按住 10 s 才进 cal_mode（十字线 30 s）；演示时按约 3 s 松开，切勿超过 10 s。

### B. U 盘视频（约 60 s）

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 选择界面 KEY0 到右，KEY1 | 进入浏览器，列出中文/英文文件 |
| 2 | KEY0 选第 1 个 mp4，KEY1 | 右侧出现 `[1]` |
| 3 | 重复选 2–3 个（含 1 张图片） | 右侧 `[2] [3]` |
| 4 | KEY0 到 `> START (3)`，KEY1 | 3 格开始播放，未用格子黑屏 |
| 5 | 短按 KEY4 | 播放弹窗（NPU/LANE/VIEW/ZEBRA） |
| 6 | KEY1 切 LANE | 播放画面上出现车道线 |
| 7 | 长按 KEY4（弹窗开着） | 只关弹窗，继续播放 |
| 8 | 长按 KEY4（弹窗关着） | 停止播放，回列表 |
| 9 | 列表根目录长按 KEY4 | 回选择界面 |

### C. 红绿灯 / 变道（约 60 s）

| 场景 | 操作 | 预期 |
|---|---|---|
| 红绿灯 | KEY0 切到直行车道 | 底部 `LN:S` |
| 红灯 | 保持停止（`MOV:0`） | 直行箭头红、`0x0C` |
| 闯红灯 | KEY1 切 `MOV:1` | 全屏红框爆闪、`0x10C` |
| 绿灯 | KEY1 切回 `MOV:0` | 直行箭头绿、`0x08` |
| 变道 | KEY2/KEY3 短按 | 虚线：绿色允许；实线：保持直行 |
| 强制变道 | 长按 KEY2/KEY3 | 实线时红箭头 + 爆闪告警 |

## 五、故障处置

| 现象 | 可能原因 | 处置 |
|---|---|---|
| 屏幕全黑 | HDMI 线/输入源；FPGA 未加载 | 换线；重新上电（先 FPGA 后 RK） |
| 彩色条纹 | 推图前未写 `0x1A0=1` 或 `0x80C/0x810` 不对 | 重启 `run_boot.sh`；跑 `rk_diag` 看 `disp`/版本 |
| 半幅残影 + DMA timeout | 旧 feed 未退出/门铃残留 | 已加进程组回收与重试；仍失败则 `stop` 后重启 S99 |
| U 盘不识别 | exFAT/分区表 | `rk_diag` 看 `usb_mnt`；换 FAT32；或手动 `mount /dev/sda1 /mnt/usb` |
| 中文文件名变 `?` | 字库缺失 | 确认 `/userdata/quad/ui_cjk.bin` 存在（2.33 MB） |
| 4 路播放起不来 | CMA 不足 | 选 3 路以内；确认 `--dec-bufs` 为 8 |
| 按键无反应 | 进了 cal_mode（KEY4 按住 10 s） | 等 30 s 或断电重启；演示时约 3 s 松开 |
| SSH 连不上 | WiFi/IP 变化 | 串口登录 `root`，`ifconfig` 查 IP |

## 六、录制注意

- HDMI 采集卡直录优先（1080p60），手机补拍硬件与按键；
- 录制前用 `rk_diag` 记录一次 PASS 截图，作为环境证据；
- 录制中不要移动板卡、不要插拔 U 盘、不要碰 P29；
- 每条镜头拍 2 遍，失败镜头按 `docs/演示视频_分镜.md` 的预案剪。

## 七、收尾

1. 长按 KEY4 回选择界面 → 断电（先 RK 后 FPGA）。
2. 备份 `/tmp/run_boot.log`、`/tmp/usb_menu_feed.log`、`/tmp/menu_daemon.log`。
3. 记录当天固件版本、U 盘内容、演示顺序，便于复现。
