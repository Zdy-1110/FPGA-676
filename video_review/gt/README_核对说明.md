## 生成器使用的规则口径（需与组委会确认后再定）

1. **右车道**：无右转灯时视为不受灯控、可通行（`--right-free`，默认开启）；加 `--no-right-free` 改为跟随直行灯。
2. **圆灯**：圆灯视为管所有方向，所以左转车道沿用圆灯状态（这类行的 conf 都标为 mid）。
3. **黄灯**：与红灯同样处理，未强制行驶时期望停车，强制行驶时期望报警。
4. **变道**：
   - 路口前实线段属于考点，生成"保持直行"和"强制变道报警"两条用例；
   - 路口内部（crossing）不生成变道用例；
   - 时长短于 0.5 s 的交集不生成用例。
5. **导航**：距离不超过 150 m（`--nav-near`）时期望已进入对应转向车道。
6. **前车过近（lead_close）**：只标在接近前车、正在刹车的阶段；静止排队时不算，不期望碰撞提醒。

## 判读中发现的、对算法有用的现象

- 113539 路口 1 的红灯内显示倒计时数字。FPGA 颜色阈值要允许灯内有黑色数字笔画，不能假设灯面是实心圆。
- 113539 路口 2 是绿灯，但车因为行人仍应停车。可见"灯为绿"不等于"可以走"，判决时危险类要优先于信号灯类。
- 112739 的导航屏会在低速时自动切到 360 环视（0–1 s、74–83 s）。导航读取模块要能识别"无导航面板"的状态，此时保持上一次的指令。
- 113343 与 113421 是同一路口，相隔约 16 s，可以拼成一条完整的"红灯排队 → 绿灯起步"测试序列。
