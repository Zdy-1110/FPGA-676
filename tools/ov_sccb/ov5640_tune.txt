#
# OV5640 运行时寄存器调优表
# 由 /userdata/quad/run_boot.sh 在检测到 FPGA 位流版本 >= 0x20261106 (cam23+) 时自动下发。
#
# 格式规范：
#   1. 寄存器行：REG VAL（十六进制，例如：0x3406 0x01）
#   2. 延迟行：sleep_ms N（毫秒整数，例如：sleep_ms 10）
#   3. 注释行以 '#' 开头，空行将被自动忽略。
#
# 20261103 板上实测（fcam_rb 30 帧 + analyze_fcam.py，室内夜间灯光）：
#   默认（高级 AWB）白区 R/G 1.058、B/G 1.067（偏品红）→ 简单 AWB 0.960、0.976
#   0x5307 0x16→0x60：像素时域噪声 4.16→3.14，行噪声 1.94→1.75；0xA0 反而变差
#   增益上限 0x3a19 降到 0x40 只会压暗画面（Y 93→40），信噪比不变，故不改
0x5183 0x94   # AWB CTRL03 bit7=1：简单（灰度世界）AWB，替代厂商高级 AWB 表
0x5307 0x60   # CIP DNS offset2（高增益段降噪强度），默认 0x16
