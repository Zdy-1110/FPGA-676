# rt_zebra_det FPGA 实时斑马线检测黄金模型

本目录包含紫光同创杯选题三（ADAS）窗口 0（960×540 RGB565）**斑马线检测模块**（`rt_zebra_det`）的 Python 定点流式黄金模型、测试向量导出工具、事件级评测脚本及参数说明。

---

## 1. 算法流程与流式硬件架构

本算法严格遵循 **「逐行流式扫描、零整帧缓存、零行缓冲」** 的 FPGA 硬件友好设计：

```text
Pixel Clock Stream (960x540 RGB565)
          │
          ▼
┌───────────────────────────────┐
│ 步骤 a: 白色像素组合逻辑判定   │ 1 cycle 组合逻辑
└──────────────┬────────────────┘
               │ is_white (1-bit)
               ▼
┌───────────────────────────────┐
│ 步骤 b/c: 行内一维游程状态机  │ O(1) 状态寄存器 (cur_w, gap, start_x)
│ 间隙合并 (gap<=4) & 边缘剔除  │ 丢弃 start_x <= 10 或 end_x >= 949 的游程
└──────────────┬────────────────┘
               │ 游程宽度有效判定 (w in [w_min, w_max])
               ▼
┌───────────────────────────────┐
│ 步骤 d/e: 行统计与多物理约束  │ 单行结束（行消隐期），纯整数乘法比较：
│ - 条纹个数与规整度判决        │ n_valid >= n_min 且 (max_w - min_w)*100*n <= reg_pct*sum_w
│ - 横向跨度约束               │ span = last_e - first_s >= 0.55 * w
│ - 白色占空比约束             │ 0.20 * span <= sum_w <= 0.60 * span
│ - 相邻间隙约束               │ 所有相邻条纹间隙 gap in [5, 100] px
└──────────────┬────────────────┘
               │ is_cand_row (1-bit, 每行一个脉冲)
               ▼
┌───────────────────────────────┐
│ 步骤 f: 帧级纵向连续性状态机  │ 逐行计数寄存器 (cur_cont, gap_rows, max_cont)
│ ROI 行统计 & 容忍 <=2 行间断  │ 帧消隐期输出 zebra_raw = (n_rows >= r_min) && (max_cont >= cont_min)
└──────────────┬────────────────┘
               │ zebra_raw (1-bit, 每帧一个脉冲)
               ▼
┌───────────────────────────────┐
│ 步骤 g: 时间迟滞滤波器        │ 连续 3 帧置位 (hyst_pos=3)，连续 6 帧清零 (hyst_neg=6)
└──────────────┬────────────────┘
               │
               ▼
       zebra_det_out (1-bit 稳定判决)
```

## 2. 算法步骤与 RTL 信号详细映射

| 算法处理阶段 | 运算/判决逻辑 (纯整数) | 对应 RTL 模块 / 信号名 | 硬件资源与时序描述 |
| :--- | :--- | :--- | :--- |
| **步骤 a: 像素级白色判据** | `r>=v_min && g>=v_min && b>=v_min && max3-min3<=c_max` | `rt_zebra_det_pixel` 模块<br>输出：`w_pixel_is_white` (1-bit) | 纯组合逻辑，直接比较 RGB565 解开的 8-bit 高位，单拍延迟 |
| **步骤 b: 行内游程提取** | 遇白色递增 `cur_w`，遇暗递增 `gap`；当 `gap > gap_max` 终止游程并结转有效宽度 | `rt_zebra_det_row` 状态机<br>信号：`r_cur_w[7:0]`, `r_gap_cnt[2:0]` | 计数寄存器，像素时钟驱动，无需行缓冲 |
| **步骤 c: 边缘剔除** | `start_x > edge_margin && end_x < (W-1-edge_margin)` | `rt_zebra_det_row` 判决<br>信号：`w_run_not_edge` (1-bit) | 边界比较器（10-bit 比较） |
| **步骤 d: 宽度过滤与统计** | `run_w >= w_min && run_w <= w_max` 则累加个数与总宽，记录首尾起点终点与间隙 | 信号：`r_row_cnt[4:0]`, `r_sum_w[11:0]`, `r_first_s[9:0]`, `r_last_e[9:0]`, `r_prev_e[9:0]` | 单行累加器与锁存寄存器，行同步信号 `hsync` 复位 |
| **步骤 e1: 规整度判决** | `(max_w - min_w) * 100 * cnt <= reg_pct * sum_w` | 信号：`w_reg_ok` (1-bit) | 2 个 DSP48 整数乘法器，行消隐期完成比较 |
| **步骤 e2: 横向跨度约束** | `span = last_e - first_s >= 528 (0.55 * 960)` | 信号：`w_span_ok` (1-bit) | 10-bit 减法器与比较器 |
| **步骤 e3: 占空比约束** | `sum_w * 100 >= 20 * span && sum_w * 100 <= 60 * span` | 信号：`w_duty_ok` (1-bit) | 16-bit 乘法与比较逻辑 |
| **步骤 e4: 相邻间隙约束** | 流式检查每相邻间隙 `g = s_curr - e_prev in [5, 100]`，若违规置位标志 | 信号：`r_gap_invalid_flag` (1-bit) | 单拍比较器，遇超限间隙锁存 1 |
| **步骤 f: 纵向连续性判决** | 在 `y in [y_top, y_bot)` 内跟踪连续行数，容忍 `gap_rows <= 2` | `rt_zebra_det_frame` 状态机<br>信号：`r_cur_cont[7:0]`, `r_max_cont[7:0]`, `r_total_cands[7:0]` | 帧寄存器，行有效脉冲驱动，零行缓冲，帧同步 `vsync` 复位 |
| **步骤 g: 时间迟滞滤波** | 连续 3 帧 `zebra_raw` 置位 1，连续 6 帧清零 0 | `rt_zebra_det_hyst` 状态机<br>信号：`r_consec_pos[2:0]`, `r_consec_neg[2:0]`, `r_zebra_out` | 帧率驱动的小计数器，输出消抖后防跳变的最终告警信号 |

```json
{
  "w": 960,          // 输入图像宽度

  "y_top": 300,      // ROI 起始行号 (避开远距离 y<300 地平线建筑栅栏/路灯干扰)

  "edge_margin": 10, // 左右边缘剔除宽度
  "w_min": 10,       // 单个斑马线条纹最小宽度 (滤除沥青麻点)
  "w_max": 70,       // 单个斑马线条纹最大宽度 (滤除大面积反光块)
  "n_min": 7,        // 单行最少斑马线条纹个数 (实测最优门限)
  "reg_pct": 120,    // 宽度规整度百分比 ((max-min)*100*n <= reg_pct*sum)
  "span_ratio": 0.55,// 横向跨度比 ((last_e - first_s) / w >= 0.55，彻底归零局部车身误报)
  "gap_min_w": 5,    // 相邻有效条纹最小间隙宽度 (像素)
  "gap_max_w": 100,  // 相邻有效条纹最大间隙宽度 (像素)
  "duty_min": 0.20,  // 白色总宽占跨度最小占空比 (滤除极稀疏反光点)
  "duty_max": 0.60,  // 白色总宽占跨度最大占空比 (滤除大面积实线)
  "r_min": 3,        // ROI 内至少候选行总数
  "cont_min": 3,     // 纵向最大连续候选行数 (允许 <=2 行断裂)
  "hyst_pos": 3,     // 时间迟滞置位帧数
  "hyst_neg": 6      // 时间迟滞清零帧数
}
```

## 4. 已知算法局限与工程对策

1. **前车近距离遮挡（如 113539 出租车）**：
   - **现象**：当大型前车或出租车紧贴斑马线停车时，车身将正中斑马线条纹完全遮挡，两侧仅露出一小截。
   - **影响**：斑马线被切为左右两部分，导致中间间隙达到约 330 像素，超出 `gap_max_w = 100` 的物理间隙上限；若只看单侧则跨度不足（span < 400 px < 528 px），因此在此类强遮挡下无法检出。
   - **工程对策**：后续系统级联时，建议由车辆检测模块在近距离检测到前车时，自适应放宽中间条纹间隙上限或分左右两侧独立统计。
2. **路面导向箭头与文字标线**：
   - **现象**：大型直行/转弯地面箭头在特定行可能出现多个分叉白色线条。
   - **对策**：由于地面箭头横向跨度通常小于车道宽度的一半（span < 450 px），`span_ratio >= 0.55`（528 px）与纵向连续性要求已将其完全滤除。
3. **中央隔离栏/金属护栏立柱反光**：
   - **现象**：车道左侧紧靠中央金属护栏时，护栏立柱在阳光或车灯照射下呈现等间距密集白色小条纹。
   - **对策**：护栏条纹仅聚集在图像左侧一隅（$x < 200$），横向跨度极窄（span < 200 px），`span_ratio >= 0.55` 可彻底防止误触发。
4. **远距离（$y < 300$）的斑马线不在 ROI 内**：
   - **现象**：距离车辆较远（> 25 米）的斑马线位于图像地平线附近（$y < 300$），由于透视缩聚，条纹宽度与间距极小。
   - **对策**：为完全避开远端地平线建筑栅栏、桥梁缆索与路灯杆的密集高频反光，算法将有效检测 ROI 严格限定在 $y \in [300, 480)$。远距离斑马线待自车行驶接近进入中近景 ROI 区域后即可稳定检出。

## 5. RTL 对照表与实现验证

### 5.1 黄金模型每一步与 RTL 信号/状态机映射对照表

| 算法步骤 (model.py) | 定点数学 / 判决表达 | RTL 状态机 / 寄存器 / 信号 | 逻辑与时序特征 |
| :--- | :--- | :--- | :--- |
| **1. 像素解开与白色判据** | `rq=r&0xF8, gq=g&0xFC, bq=b&0xF8`<br>`rq,gq,bq >= 140 && max-min <= 30` | `is_white` (1-bit 组合逻辑) | 纯组合逻辑，复现 `r5<<3 / g6<<2 / b5<<3`，0 周期缓存 |
| **2. 行内一维游程提取** | 遇白递增 `cur_w`，遇暗递增 `gap`；当 `gap > 4` 判定游程终止并计算起止与宽度 | `cur_w[9:0]`, `gap_cnt[3:0]`, `start_x[9:0]`<br>`FSM_ACTIVE` / `FSM_FINISH_RUN` | 流式计数器，像素时钟同步驱动，行末结转未结束游程，无行缓存 |
| **3. 游程边界与宽度滤波** | `start_x > 10 && end_x < 949`<br>`run_w in [10, 70]` | `run_valid_act` / `run_valid_blk` (1-bit)<br>`runs_valid[7:0]`, `sum_w[11:0]` | 纯定点比较器，合格游程即时累加条纹总宽与有效条纹计数 |
| **4.1 条纹个数与规整度** | `runs_valid >= n_min(7)`<br>`(max_w - min_w)*100*n <= reg_pct(120)*sum_w` | `cond_n` (1-bit), `cond_reg` (1-bit)<br>`mult_diff[17:0]`, `term_reg1[25:0]` | 行消隐期（FSM_EVAL_ROW）计算，纯整数乘法比较，无除法 |
| **4.2 横向跨度约束** | `span = last_e - first_s`<br>`span * 1000 >= 550 * 960 (528000)` | `span[9:0]`, `cond_span` (1-bit)<br>`term_span_lhs[19:0]`, `term_span_rhs[25:0]` | 10-bit 减法与定点乘法，有效滤除局部车身/箭头误报 |
| **4.3 条纹占空比约束** | `20 * span <= sum_w * 100 <= 60 * span` | `cond_duty` (1-bit)<br>`term_duty_lhs[17:0]`, `term_duty_min/max_rhs` | 纯整数乘法窗口比较，滤除稀疏孤立反光或大面积实线 |
| **4.4 相邻条纹间隙约束** | 流式相邻条纹间隙 $g = s_{curr} - e_{prev}$<br>所有间隙需满足 $g \in [5, 100]$ | `gap_invalid` (1-bit 粘性寄存器)<br>`cond_gap` (1-bit) | 流式比较，发现越界间隙单拍置位粘滞标志，无行缓冲 |
| **5. 候选行综合判决** | `cand = cond_n && cond_reg && cond_span && cond_duty && cond_gap` | `row_cand` (1-bit 寄存器) | 行消隐第 2 周期完成锁存输出 |
| **6. 帧级纵向连续性追踪** | 仅扫描 $y \in [300, 480)$，跟踪连续行数，容忍 $\le 2$ 行断裂；帧末判决 `zebra_raw` | `cur_cont[7:0]`, `gap_rows[7:0]`, `max_cont_acc[7:0]`<br>`zebra_raw = (n_rows>=3) && (max_cont>=3)` | 行消隐第 3/4 周期更新，帧消隐期锁存 `zebra_raw/n_rows/y_min/y_max` |
| **7. 时间迟滞滤波器** | 连续 3 帧检测置位 1，连续 6 帧未检出清零 0 | `consec_pos[7:0]`, `consec_neg[7:0]`, `zebra` | 帧率小计数器，消除告警抖动，提供稳定最终告警 |
