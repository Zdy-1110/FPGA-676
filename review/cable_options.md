# PCIe 短柔性延长组件采购方案

核查日期：2026-10-03（Asia/Shanghai）。

范围：只核实制造商一手产品页、订购选项、原理图和规格书；不修改原理图、PCB、嘉立创 EDA 工程，不下订单。本报告是采购与接入风险评审，不是制板或直接通电许可。

## 1. 结论与建议采购规格

**优先方案：购买完整 PCIe CEM x4 公头金手指—x4 母槽柔性延长组件，另做一块短电源隔离转接板。不再为自定义 FPC pinout 采购普通排线。**

### 建议先询价/购买的一件组件

- 制造商：**ADT-LINK**。
- 型号字段：**R22SF**。
- 长度字段：**Cable Length = 10cm，即 100mm 可见线缆长度**。
- 接口：PCIe x4 公头金手指至 PCIe x4 母槽；SF 是厂商所称 180°夹板式垂直出线形式，必须结合实物方向确认，不仅凭“直插”一词选型。
- 制造商标称：PCIe 3.0 x4；本项目**不以 Gen3 x4 为实际运行目标**。
- 若 100mm 会导致连接器受拉、线缆折死角或干涉开发板，改选 **同一 R22SF 型号，Cable Length = 15cm（150mm）**。
- 官网产品页及独立订购页均已读取，型号和 10/15cm 选项明确存在；这不是库存、交期或系统互通保证。[S1] [S2]

**前提：FPGA 实际接入端要能与标准 CEM x4 母槽配合，例如标准 x4 卡边金手指。**本轮未现场核实 FPGA 接口照片、卡边朝向和插接空间。若 FPGA 端实际上也是母槽，公头—母槽组件不能直接完成连接；不能靠反插、硬接或随意交换 TX/RX 解决，需另行审核双公跳线及对应隔离拓扑。

### 两个备选方向

1. **M22SF + Cable Length 10cm/15cm**：制造商标称 PCIe 4.0 x4，官网独立订购页存在对应选项。可作为供货或结构更合适时的替代；本轮没有核实 M22SF 当前批次对应的差分阻抗规格，不将其他系列的 85Ω/95Ω数据套给它。[S4] [S5]
2. **K22SF-BK + Cable Length 10cm/15cm**：制造商标称 PCIe 5.0 x4；产品页链接的专用屏蔽线材资料给出 85±5Ω，资料更详细。**其产品页有型号和长度选项，但网页链接的独立 K22V5-Shop 页面本轮返回 404**，因此先向制造商询价确认批次及供货，不写成“独立商城页可直接购买/已确认现货”。Gen5 标称不会让本项目变成 Gen5，也不代表加入自制板后仍有完整通道保证。[S7] [S8]

不必为了 FPGA/RK 的 Gen2 目标追求 Gen5 标签。首选 R22SF 的理由是标准 x4 公母拓扑、公开无源电路图及明确 100/150mm 订购选项；**不是已经完成了这两块开发板的信号完整性验证**。

## 2. 本项目的输入条件与链路上限

以下采用用户提供的板卡资料结论，不把旧草稿中 OK3588 等文件名当作本次主机身份：

| 项目 | 本次输入 |
|---|---|
| RK 主机 | 飞凌 RK3568，原理图 OK-3568-UP4 V1.3-A |
| 主机接口 | P29，物理 PCIe x4 槽，仅引出 lane0/lane1 |
| FPGA | 盘古100Pro+，PCIe x4 Gen2 能力 |
| 供电要求 | 两块开发板各自独立供电，不跨接插槽电源；保留信号参考地 |

工程判断：

- 购买 x4 组件是为了**物理配合及完整 lane0/1 通道**，不会补出主机不存在的 lane2/3。
- 可考虑的目标是 **Gen2 x2**，前提是 FPGA Endpoint 配置/IP 支持 x2 窄链路或正确的降宽训练；不能仅凭“x4 Gen2 IP”就保证能协商 x2。
- 必须确认 RK 为 Root Complex、FPGA 为 Endpoint，以及参考时钟、复位和软件配置兼容。延长组件本身不解决这些问题。
- 初次联调可先使用双方支持的更保守速率/宽度，完成基本枚举后再验证 Gen2 x2；不能承诺 Gen2 x4。

## 4. 线材与阻抗：不能混用各系列数据

### 4.1 R22SF：旧版原线规格是 95Ω，不是 85Ω

已读取并渲染复核制造商文件 `ADT_R22SF Cable specification 20200107.pdf`：

- PDF 第 2 页是 R22 系列连接图，含 x4 数据、REFCLK、PERST#、GND 与电源路径；公开版本为无源连接结构，不能因此忽略当前批次版本核对。
- PDF 第 3 页给出的线材差分阻抗为 **95Ω**；另有对内阻抗匹配参数，但不能把它改写成厂家没有写出的总阻抗容差。
- 图示采用 30AWG 导线，线材厚度约 1.4mm；这是专用柔性扁平线，不是据此就能换成通用 0.5mm pitch FFC 的 pinout。

该文件日期为 **2020-01-07**，是公开旧版本，不是 2026 年批次证明。95Ω本身也不构成“本项目肯定不兼容”的结论；应以当前整组件数据和实际通道验证判断，但**不能宣传 R22SF 已有 85Ω规格依据**。[S9]

### 4.2 K22SF-BK 网页链接的新版线材有明确参数

已读取并渲染复核制造商文件 `ADT-Cable 24P 5.0 specification 20250625.pdf`，图号 `ADT-24P-5.0`，日期 **2025-06-25**：

| 项目 | 制造商线材规格 |
|---|---|
| 原线描述 | 24Pin、6 组差分对 |
| TDR 差分阻抗 | **85±5Ω** |
| 对内时延偏差 | ≤10ps/m |
| 截面尺寸 | 厚 0.82±0.08mm，宽 12.0±0.50mm |
| 结构 | 30AWG 镀银铜、FEP 绝缘、差分对铝箔屏蔽及排流线 |
| 弯曲要求 | 最小弯曲半径不小于 5×OD；不得承受强机械应力 |

这些是**原线材**数据，不是包含两端 PCB、连接器和自制隔离板的端到端通道测试结果；原线截面宽度也不是成品整个线束/端板宽度。扁平结构的实际折弯方向及 OD 定义应向厂家确认，不擅自把 0.82mm 厚度代入为一个承诺的最小弯曲半径。[S8]

`24Pin/6对` 不是本项目自定 FPC 的采购 pinout。按 lane 定义，完整 x4 需要 8 组数据差分对，通常还需单独处理 REFCLK；不能拿一条该名称的裸线就替代整个 x4 组件。制造商的端板和线束组合才完成具体映射。

### 4.3 厂商速度标称不是本项目测试结论

- R22、M22、K22 产品页分别有 Gen3/Gen4/Gen5 标称；本轮没有核实它们在 PCI-SIG 认证清单中的资格，也没有对这两块开发板做 BER/眼图/一致性测试。
- 厂商 K22 Gen4 页面自己说明，长线实验结果受板卡与驱动条件影响，不能保证所有系统满速。短线采购同样不应被写成“加入任意 PCB 后必跑满速”。[S6]
- 本轮没有获得与目标 100/150mm 具体组件、两端过渡和自制板完全匹配的完整 S 参数或合规报告。高代际标称、单独线材阻抗、基本导通测试都不能替代这项验证。

## 5. 推荐接入拓扑与独立供电边界

以下以 FPGA 侧是标准 x4 卡边金手指为条件：

```text
RK P29 x4 母槽
  → 成品延长组件的 x4 公头金手指
  → 100mm 专用柔性线缆
  → 成品延长组件的 x4 母槽
  → 短隔离板的 x4 公头金手指
  → 短隔离板的 x4 母槽
  → FPGA x4 卡边金手指
```

这样只需自行设计**一块短转接/隔离板**，不需要两块自定 FPC 端板。隔离板同样增加 PCB 过渡和插接界面，仍需控制阻抗、保持连续 GND 参考和实测互通；“短”不等于自动没有信号完整性风险。

### 5.1 普通成品延长组件不是电源隔离组件

R22 公开原理图含 +12V、+3.3V、3.3VAUX 跨接路径；不能把成品组件不带外接电源线理解为“不会互相供电”。K22 V2.0 公开连接图也列有这些电源的传递路径，并非电源隔离设计。[S9] [S10]

以 R22 厂商 CEM 图中触点标注为核对起点，短隔离板应检查以下电源触点，**两端之间不连接**：

| 电源 | CEM x4 触点 |
|---|---|
| +12V | A2、A3、B1、B2、B3 |
| +3.3V | A9、A10、B8 |
| 3.3VAUX | B10 |

此表不是对现有自定义符号/封装正确性的认可，仍须逐脚与 RK、FPGA 原理图及实物核对。**仅删除一个电源铺铜层不够**：其他层走线、过孔、焊盘、短接/跳线和器件都可能重新形成通路。

在上图端点隔离板位置，上游延长组件中的电源导体仍可能由 RK 带电，只是在进入 FPGA 前被截断。若要求线缆段也不带插槽电源，可重新评估把同样的隔离板放到 RK 槽后；机械布局和存在检测路径要随之检查。

### 5.2 地、时钟、复位与其他侧带

- 保留数据与 REFCLK 的 GND 回流/参考路径，不能因“只留信号”而把地平面也移除。这是**阻断电源传输且共地**，不是 galvanic isolation（电气绝缘隔离）。
- R22 厂商图中的 REFCLK 是 A13/A14，PERST# 是 A11；采购及隔离板都要确认其传递与电压域，而不是沿用旧草稿中的错误/未核实编号。[S9]
- WAKE#、SMBus、PERST# 等即使不传主电源，也可能经上拉或保护结构造成掉电反灌。两板独立供电不自动解决信号域兼容；必要时另行设计电平/掉电保护。
- 旧 R22 资料存在 CLKRUN# 名称，插槽符号中 B12 又标成 RSVD；新 K22 图也有相关命名。**不能据此盲认它就是 RK 使用的 CLKREQ#**；该脚是否需要、是否传递及上拉来源均须查实际两板电路。[S9] [S10]
- PRSNT# 的路径要按 RK 插槽和实际接入形式核对，不在本采购报告中假定“全部接地”就是正确方案。
- 不接额外 SATA/Floppy 电源注入线。M22 页面中的 `-PW` 表示带外接电源连接器/线缆的选项，本项目不以这种方式把两板电源并起来。[S4]

## 6. 与“两块自制板＋高速 FPC”的采购可行性对比

| 项目 | 成品 x4 公母延长组件＋一块短隔离板 | 两块自制端板＋单独采购高速 FPC |
|---|---|---|
| 线缆选型身份 | 已有明确制造商型号，100/150mm 长度可独立指定 | 必须同时确定 FPC 结构、pinout、接地、长度及两端连接器 |
| 本轮可核实采购项 | R22SF/M22SF 等官网选项已核实 | **未核实与本项目自定 pinout 匹配且有完整高速资料的现货组件** |
| 装配映射 | 厂商承担其端板到专用线束的映射；仍要确认必需侧带 | 自己承担两端封装方向、正反面触点及 pin-to-pin 映射 |
| 高速证据 | 有代际标称及部分公开线材/电路资料；不是本系统保证 | 单独连接器“支持 PCIe”不能证明所买裸 FPC 与整通道合格 |
| 电源隔离 | 在短板上定义明确断点，能单独验证 | 两板都要审核电源、地与侧带，定制线的电源映射也要验证 |
| 首版代价 | 较少定制接口变量，但增加短隔离板插接过渡 | 更多信号完整性和采购变量，可能需要厂商定制与样品验证 |
| 本轮建议 | **优先落地** | 后续空间/结构确有必要再开发，不作为第一版默认方案 |

上述为基于已核实产品资料的工程判断，不是关于所有供应商库存或定制能力的市场结论。若以后某厂商能提供“匹配连接器＋受控阻抗 FPC＋固定 pinout＋指定长度＋对应测试资料”的完整配套，才值得把它与当前成品方案比较；本轮不编造这种现货 FPC 的型号、MOQ 或交期。

## 7. 可复制给制造商的询价描述

如果供应商建议 M22SF 或 K22SF-BK，应保留其**完整型号**及对应 10/15cm 长度，不以“都是 ADT x4”混发；K22SF-BK 的 85±5Ω线材证据要与实际交付批次匹配。

- [ ] FPGA 的实际物理接口、卡边方向与两端板的插接净空符合本拓扑。

### 接入前最低检查

- [ ] 在线缆/隔离板脱离开发板且全部断电时，对照图纸检查映射、短路、必要 GND 与信号通路。

- [ ] REFCLK、PERST#、PRSNT# 及实际需要的侧带已完成原理图/电压域审核；基本导通测试不等于高速验证。
- [ ] 已安装隔离板再连接两块独立供电开发板；**不要先用未隔离的成品延长线直连试机**。
- [ ] 断电插拔，不假定此自制组合支持热插拔；上电顺序按两块板和 FPGA IP 的要求安排。
- [ ] 验证实际协商代际/宽度、长时间传输错误与复位恢复，记录完整组件型号和长度。

## 8. 调研限制与一手来源

- 本轮 `web.run` 没有返回可读检索结果，使用 **requests 直接读取制造商官网**，并用独立 `agent-browser` 会话核对产品页面；没有用经销商页面、论坛或视频补齐缺失规格。
- `pcb scan` 在本环境不可用；制造商两份规格 PDF 使用 PyMuPDF 提取文本，并渲染相关页面进行人工视觉核对。
